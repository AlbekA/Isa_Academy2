## 2. Ключевые возможности сайта

### Интеллектуальный поиск по источникам
- Поиск по заголовкам, содержимому, категориям, тегам и метаданным файлов.
- Мгновенное ранжирование по релевантности, дате и названию.
- Подсветка найденных поисковых слов в сниппетах (`<mark>`).
- **Блок «Краткий ответ» (Smart Answer):** Детерминированный фактологический синтез ответа строго по источникам с указанием точных цитат и ссылок на файлы (без выдумок).
- **Сохранение в истории последних двух диалогов:** В соответствии с требованием пользователя система автоматически фиксирует и сохраняет в `localStorage` ровно **последние 2 диалога** (поисковый запрос, краткий ответ, цитируемый первоисточник) с возможностью восстановить диалог в 1 клик через всплывающую панель «История 2 диалогов».

### Конверсионная архитектура (Mobile-First)
- Соответствие обязательному стандарту мобильной адаптации:
  - Минимальная область нажатия $\ge 44 \times 44$ px для всех кнопок и ссылок.
  - Высота инпутов $\ge 48$ px, шрифт 16px (исключает автозум в iOS Safari).
  - Липкая мобильная панель быстрых действий (звонок, WhatsApp, запись на урок) строго в рамках $\le 15\%$ высоты мобильного экрана.
  - Полнофункциональное мобильное меню-шторка.
  - Отсутствие горизонтального скролла на всех ширинах (320px, 360px, 375px, 390px, 430px, 768px, 1024px, 1440px).

### Форма заявки и CRM
- Запись на бесплатный пробный урок и определение уровня по шкале CEFR.
- Валидация полей: имя, телефон с кыргызстанским кодом `+996`, выбор курса, формата (офлайн/онлайн) и времени.
- Защита от спам-ботов через honeypot.
- Сохранение лидов в память браузера + кнопка «Экспорт заявок (CRM JSON)» в футере сайта.
- Праздничный салют (confetti) при успешной отправке.

## 4. Как запустить проект

1. Установка зависимостей:
   ```bash
   npm install
   ```

2. Запуск в режиме разработки:
   ```bash
   npm run dev
   ```
   Сервер запустится на `http://localhost:3000`.

3. Сборка для продакшна:
   ```bash
   npm run build
   ```

4. Проверка типов и линтинг:
   ```bash
   npm run lint
   ```

## 5. Добавление новых источников

Для добавления нового учебного документа, программы или регламента откройте файл `/src/data/sources.ts` и добавьте объект типа `SourceDocument`:

```typescript
{
  id: "src-unique-id",
  slug: "my-new-program",
  title: "Название источника",
  description: "Краткое описание для карточки",
  category: "Английский язык", // или Немецкий язык, Русский язык, Тарифы и оплата, Методология и правила, О центре и локации
  tags: ["Тег1", "Тег2"],
  type: "md", // или "pdf", "docx", "table", "json"
  date: "2026-03-30",
  file: "/sources/my-file.md",
  chunks: [
    {
      id: "chunk-1",
      title: "Заголовок фрагмента",
      pageOrSection: "Раздел 1",
      text: "Полный текст фрагмента, по которому будет производиться поиск..."
    }
  ],
  content: "Полный Markdown текст документа..."
}
```
Поисковый индекс обновляется мгновенно без пересборки.
